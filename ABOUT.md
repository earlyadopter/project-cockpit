# CLI and dashboard for many AI-assisted projects

cockpit is a local CLI plus localhost dashboard for working on many AI-assisted projects at once. It shows live git, tmux and Claude Code agent status recomputed on every call, gives each project a tmux workspace, runs declared actions under server-enforced safety tiers, and tracks a per-project plan.md. It is open source and free by decision, with remote access over Tailscale with token auth, and is positioned as mission control for a portfolio of projects, launched with an essay before a Show HN.
